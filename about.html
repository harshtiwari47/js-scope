About JS-Scope

Interactive JavaScript Execution Engine & Memory Inspector

JS-Scope is an advanced educational tool designed to demystify JavaScript execution dynamics. Built with a 3D Neumorphic interface, JS-Scope parses user JavaScript code using Acorn AST parsing, instruments execution line-by-line, and captures granular step-by-step state snapshots.

Core Visualization Modules

Call Stack & Scope

Inspect active stack frames, lexical scopes, local variables, and closure bindings in real-time as execution steps forward or backward.

Heap Memory

Track dynamic object allocations, hex address references (e.g. 0x10A1), array properties, and reference mutations.

Array & Sorting

Visualize array algorithms (Bubble Sort, Quick Sort, Binary Search) with 3D bar blocks, comparing highlights, swapping indicators, and index pointers.

Event Loop & Async

Understand asynchronous JavaScript by visualizing the Call Stack, Web APIs background threads, Microtask Queue (Promises), and Task Queue (setTimeout).
